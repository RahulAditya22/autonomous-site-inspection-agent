# Demo

1. Start Flask on port 5000.
2. Start Vite on port 5173.
3. Click **Run deterministic demo**.
4. Watch telemetry and structured agent events update.
5. D-01 starts at 85% and battery degradation after the second waypoint makes the remaining route unsafe, so the planner records a replan and return-home action.

The image fixtures are generated locally and sent through the actual perception interface. They are not a benchmark dataset and filenames are never used as detection signals.
